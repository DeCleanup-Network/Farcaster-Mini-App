# Scripts to Keep (Ongoing Operations)

## Admin Management
- addVerifier.js - Add verifier to VerificationContract
- addVerifierToPointsDistributor.js - Add verifier to PointsRewardDistributor
- removeVerifierFromPointsDistributor.js - Remove verifier
- awardPoints.js - Manually award points

## Configuration Updates
- updateTokenPrice.js - Update token price
- updateTargetRewardValue.js - Update target reward value
- updatePointMultipliers.js - Update point multipliers
- setFeeTreasury.js - Set fee treasury address
- updateBaseURI.js - Update NFT metadata URI

## Token & Fee Management
- transferFromDeployer.js - Transfer tokens to contract
- withdrawFees.js - Withdraw collected fees

## Monitoring & Checks
- checkUserStatus.js - Check user points, level, verifier status (comprehensive)
- checkDistributorBalance.js - Check contract token balance
- checkDeployerBalance.js - Check deployer wallet balance
- checkAllFees.js - Check all fee settings and balances
- checkContractOwners.js - Check contract ownership
- checkFeeTreasury.js - Check fee treasury configuration
- checkPointsDistributorOwner.js - Verify contract owner

## Operations
- verifyCleanup.js - Verify cleanup submissions
- transferOwnershipToMultisig.js - Transfer ownership to multisig (for mainnet)
